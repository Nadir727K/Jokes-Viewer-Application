## 📌 Description

This project is a React-based web application that fetches and displays random jokes using a public API. The goal of this project is to understand API integration, state management, and building an interactive user interface.

The application allows users to browse jokes easily and load new ones dynamically with a button click.

---

## 🚀 Features

* Fetches jokes from a public API
* Displays jokes in a clean, readable format
* “Next Joke” button to browse through jokes
* Automatically fetches new jokes when current list ends
* Loading and error handling states
* Modern glassmorphism UI with smooth interactions

---

## 🛠️ Tech Stack

* React (Vite)
* JavaScript (ES6+)
* CSS (custom, modular, glassmorphism design)

---
